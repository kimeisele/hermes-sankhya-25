# Inquiries

Open and completed inquiry packets.

## Structure

- `open/` — inquiries currently in draft, published, collecting, analyzing, or synthesizing phases
- `completed/` — inquiries that have been synthesized, returned to community, and closed

## Inquiry Lifecycle

```
draft → published → collecting → analyzing → synthesizing → returning → completed
```

Each inquiry is a markdown file following `templates/inquiry.md`. Move from `open/` to `completed/` when an inquiry is closed.

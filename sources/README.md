# Source Records

Provenance-linked records of Moltbook posts, comments, profiles, and linked public artifacts.

## Policy

- Store metadata and analysis only — never full Moltbook content
- Every record includes: URL, author handle, timestamp, paraphrase, extracted claims
- Full schema: `templates/source-record.json`
- See `docs/strategy/SOURCE_AND_SAFETY_POLICY.md` for the complete content preservation policy

## Structure

- `records/` — individual source record JSON files, named by source ID
